# Task: build phases 1–5 of the Check Climate Africa site

Read `AGENTS.md` and `docs/PLAN.md` first, then the skills and design files they list. Work through the phases below in order on a git branch `dev` (create it from `main`). Commit at the end of each phase. Do not push, do not deploy, and do not touch anything outside this repo.

## Phase 1 — Scaffold

- Create an Astro + EmDash project in the repo root with pnpm (use the current EmDash starter/blog template or `pnpm create` flow that the docs describe; check Context7 `/websites/emdashcms` for the current command). Node 24 target (`engines`), `.nvmrc` = 24.
- `astro.config.mjs`: `@astrojs/node` standalone, EmDash with `sqlite({ url: file:${DATABASE_PATH} })` (default `./data/checkclimate.db` in dev), storage `s3()` when `S3_BUCKET` is set else `local()`, `memoryCache` object cache, `fsLite` sessions in `SESSION_DIR` (default `./data/sessions`), `trustedProxyHeaders`, `site` from `EMDASH_SITE_URL`.
- Install `@aws-sdk/client-s3` and `@aws-sdk/s3-request-presigner` (needed by `s3()`).
- `.env.example` with: `EMDASH_SITE_URL`, `DATABASE_PATH`, `SESSION_DIR`, `EMDASH_ENCRYPTION_KEY`, `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_REGION`, `S3_PUBLIC_URL`, `RESEND_API_KEY`, `EMAIL_FROM`, `CLAIMS_INBOX`, `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY`, `CF_ZONE_ID`, `CF_PURGE_TOKEN`.
- `.gitignore` (node_modules, dist, .astro, data, *.db*, .env, CLAUDE.md, migration/*.xml).
- `src/styles/tokens.css` generated by `scripts/build-tokens.mjs` from `design/system/project/tokens.json` (add as a `prebuild`/`predev` script). `src/styles/global.css` with base styles.

## Phase 2 — Schema and seed

- Collections `posts`, `pages`, `claims`; taxonomies `category`, `tag`; menus `primary`, `footer`; bylines — exactly as `docs/PLAN.md` "Content model" says.
- Seed (`seed/seed.json`) with the 7 nav categories (WordPress slugs: agriculture, aviation, environment, fact-check, green-energy, news, sustainability), the menus, and the sample stories used in the page designs (the article, the fact check with claim/verdict filled, ~10 archive items, one ALERT story), plus pages About, Contact, Privacy, Accessibility. Use the copy from the `.dc.html` files. No lorem ipsum.
- Generate types with the EmDash CLI.

## Phase 3 — Layout, components, templates

- `BaseLayout` (head/SEO via EmDash SEO helpers, og tags with image width/height, theme no-flash script, skip link), `Header` (top bar with date, weather slot, theme toggle; logo + strapline; search; Submit a claim; category nav from the `primary` menu; mobile menu), `Footer` (from the design + `footer` menu + settings).
- Components from `design/system/project/components/*`: SectionHeading, CategoryTabs, HeroStory, StoryCard, StoryList, AlertBanner, FactCheckBand, ClaimCard, VerdictPanel, ShareBar, Breadcrumb, TagList, Pagination, BackToTop, ThemeToggle, WeatherCard.
- Routes from PLAN.md "Routes": home, post (article vs fact-check by `kicker`), category/tag/author/posts archives with pagination (`/page/[n]/`), generic page, about/contact, submit-a-claim, search.
- Portable Text rendering with styles for h2, blockquote (pull quote), lists, links, images with captions, embeds (YouTube/X).
- Light/dark both correct. Responsive at 1440 / 900 / 600 / 360.

## Phase 4 — Dynamic features

- Weather island (Open-Meteo, geolocation, default city from settings, 30-min localStorage cache, graceful failure).
- Claim form → `claims` entry, optional file upload to storage, Turnstile check server-side, notification email via the Resend plugin, thank-you state. Validate with zod (`.nullish()` for optional fields).
- Comments (EmDash comments, moderated, Turnstile).
- Search page, `/feed/` RSS (+ `/category/[slug]/feed/`), sitemap at `/sitemap.xml` with `/sitemap_index.xml` redirect, `robots.txt` (Disallow `/admin`, `/_emdash`).
- Redirects middleware: `/wp-admin*`, `/wp-login.php`, `/login` → `/admin/` (302); `/wp-content/uploads/*` → lookup in `migration/media-url-map.json` (301; 404 if missing; empty map is fine for now); `/megamenu/*` → 410; `/?p=<id>` → post by WordPress id if stored.
- `src/pages/admin.astro`: branded editor landing page per the deploying skill (noindex header + meta).
- Site settings plugin (contact email, socials, weather default city) merged over hardcoded defaults.

## Phase 5 — VPS deployment files (do not run them)

- Middleware for `Cache-Control` and `Cache-Tag` exactly as `vps.md` describes.
- `plugins/cloudflare-purge/` (native plugin, purge by tag, debounced afterSave for published only, 429 retry) and `plugins/resend-email/` (native email transport). Unit-test both with mocked `fetch` (vitest).
- `deploy/checkclimate.service` (systemd, hardening from vps.md, absolute fnm default-alias node path placeholder), `deploy/nginx-checkclimate.conf` (Cloudflare-only via `geo $realip_remote_addr`, realip, Origin Cert paths, proxy to 127.0.0.1:4321, `/wp-content/uploads` handled by the app), `deploy/env.example`.
- `scripts/deploy-vps.sh` (refuse dirty tree, `git pull --ff-only`, `pnpm install --frozen-lockfile`, build, restart, origin smoke test), `scripts/backup.sh` (sqlite3 `.backup`, integrity check, 14-day local retention, rclone to `checkclimate-backups` with `no_head`).
- `scripts/post-import.ts` and `scripts/verify-migration.ts` as described in PLAN.md "Content migration" steps 5–6 (dry-run by default).
- `.github/workflows/ci.yml` (dev: install, typecheck, test, build) and `deploy.yml` (main: SSH deploy + Cloudflare purge_everything), using secrets `VPS_HOST`, `VPS_SSH_KEY`, `VPS_KNOWN_HOSTS`, `CF_ZONE_ID`, `CF_PURGE_TOKEN`.
- `docs/RUNBOOK.md`: server setup steps, env names, migration-lock fix, backup/restore, rollback, cutover checklist (copy from PLAN.md and vps.md).

## Finish

Run `pnpm build`, `pnpm typecheck`, `pnpm test`. Start the built server, load every route once (curl to 127.0.0.1) and confirm 200s (404 for a missing slug). Write `docs/STATUS.md`: what was built, what was verified and how, what is stubbed or left for the owner (credentials, WordPress export, DNS), and any deviation from the design with the reason.
