# StoryCard

The standard story teaser in grids and carousels: a photo, then the category, the headline and the byline with reading time.

- Image: 3:2, radius `radius` (10px). The preview uses green fills in place of photos.
- Category: `label` style, `ink-muted`; hover `amber-soft`.
- Headline: `card-title` style (24px / 700), `ink`; hover `brand-forest`.
- Meta: author in `byline` (16px / 500, `ink`), reading time in `meta` (12px, `ink-meta`).
- Cards stack with `space-5` (30px) between rows.
- Consumer provides: the image, links, author and reading time.
