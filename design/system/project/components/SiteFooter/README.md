# SiteFooter

The closing band of every page: the contact invitation, a line on the mission, the About / Privacy / Contact links and the copyright.

- Band: `surface-footer` (#E7E7E7), padding `space-5` × `space-2`.
- Text: 16px `ink-body`. The email link is `brand-forest` (or `brand-amber` in dark mode).
- Links: 14px / 500.
- Copyright: `meta` style in `ink-meta`.
- The contact line invites readers to send in climate claims. Keep that invitation: it is how fact-check leads arrive.
