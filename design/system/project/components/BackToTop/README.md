# BackToTop

A round floating button, fixed to the bottom-right corner, that scrolls the page back to the top.

- Circle `fab-size` (50px), fill `leaf`. The arrow is `ink`: black on `leaf` passes as a non-text icon (6.5:1). Avoid a white arrow (3.2:1).
- Appears after the reader scrolls (the theme's `active-scroll-to-top`).
- Always give it `aria-label="Back to top"`.
