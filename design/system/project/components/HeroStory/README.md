# HeroStory

The lead story at the top of the homepage and of each section: a full-width photograph with the category and headline set in white over its lower edge.

- Image: radius `radius` (10px), cropped to fill. The preview uses a `brand-deep` fill in place of a photo.
- Category: `label` style in `on-image` (#F0F2F5); it turns `amber-soft` on hover.
- Headline: `hero-title` style (30px / 700), `on-brand`.
- A dark fade sits behind the text so the white stays readable on any photo. Its exact values are assumed; the site's own is not a token.
- Headlines keep the newsroom prefixes when they apply: "FACT CHECK:", "ALERT:".
- Consumer provides: the photo, category link and headline link.
