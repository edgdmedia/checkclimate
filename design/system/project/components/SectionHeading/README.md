# SectionHeading

The title that opens each homepage block (Top Stories, Latest Factchecks, News), with an optional "See All" link on the right.

- Title: `section-title` style (36px / 700), `ink`.
- Link: `byline` style (16px / 500). The live site colours it `leaf`, which is 3.2:1 on white; this system uses `brand-forest` at rest and `leaf` on hover.
- Copy is short and plain: a noun phrase, Title Case, no punctuation.
- Consumer provides: the title and the link target.
